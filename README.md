One-line commuter forecast for make.fun's "Charm the Commuter: Forecast a City That Isn't" bounty. A single original forecast for the fictional city Grumbletown — expect light rain and a 90% chance your bus is already late, pack an umbrella and low expectations, and wave anyway. The program writes the forecast (133 characters, one line) to `/output/entry.txt`, validating it against the competition gate (1–140 characters, not only whitespace, single line) and reading it back to confirm exactly what was written.

## Run it

```sh
node main.ts
```
